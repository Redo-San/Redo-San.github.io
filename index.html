One binary.
Every authenticity tool.

The same engine that powers the web app ships as a command-line interface — 14 commands for watermarking, fingerprinting, provenance and more. Install once, script it anywhere.

  • Node.js 22+ · zero native deps beyond canvas
  • Pipe-friendly JSON output on every command
  • GPL-2.0 · source on GitHub
zsh — redo-san 
# Install once
$ npm install -g redosan-authenticity-cli

# Embed an invisible watermark
$ redosan watermark embed -i photo.png -s secret.png -a lsb -p mypassword -o out.png

# Verify a fingerprint (JSON output)
$ redosan fingerprint file.bin --algo sha256 --json

# OpenTimestamps proof
$ redosan timestamp create doc.pdf -o proof.ots

# Read EXIF metadata
$ redosan metadata shot.jpg --json
